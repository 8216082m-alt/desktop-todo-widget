# 桌面待办

一个 Windows 11 桌面待办挂件。添加截止时间和多行备注，按逾期、今天、之后和无截止时间查看清单。勾选即可完成待办，也可以从「已完成」恢复。

## 下载与使用

1. 在 [Releases](https://github.com/8216082m-alt/desktop-todo-widget/releases/latest) 下载 Windows x64 压缩包，解压到你想长期存放的文件夹。
2. 双击 **桌面待办.exe**，点击 **新增**。标题必填，截止时间和备注可选。
3. 拖动挂件顶部空白处可以移动位置。隐藏后，从任务栏右下角的托盘图标重新打开。
4. 首次打开会启用登录后自动启动。可在挂件右上角的 **⋯ → 设置** 中关闭。

有截止时间的待办默认提前 1 小时和到期时提醒，可逐条调整。关闭挂件窗口后，托盘仍会运行。应用再次启动或电脑从休眠恢复时，会检查错过的到期提醒。通知显示受 Windows 通知设置影响。

待办、备注和窗口位置保存在当前电脑的 `%LOCALAPPDATA%\DesktopTodoWidget`。

## 构建和测试

使用 Windows x64 自带的 .NET Framework 4.x 编译器。在 PowerShell 中运行：

```powershell
.\build.ps1
.\build.ps1 -Verify
```

可执行文件生成到 `dist`。测试覆盖提醒时机、补提醒、重启去重、多行备注、位置保存、备份恢复和自启动开关。
